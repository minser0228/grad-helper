# 검증 사례 — 예상 정답과 실제 결과

판정이 맞는지 확인하려고, 사례마다 **예상 정답을 규칙 문서(2026 학사종합안내·학과 교육과정·학과 공지)로 먼저 손으로 계산**하고, 도구의 계산 결과와 비교했다. 모든 사례는 자동 테스트(`test/engine.test.js`의 「사례 1~6」)로 들어가 있어서, 코드를 고칠 때마다 다시 확인된다.

```bash
node --test test/*.test.js
```

## 기준 학생 (가상)

[sample.js](../sample.js)의 가상 학생이다. 첫 화면의 「▶ 샘플로 체험하기」로 같은 학생을 볼 수 있다. 실제 학생 정보가 아니다.

- 24학번 일반 재학생, 3학년 2학기 (24학번 교육과정: 졸업 130 · 전공 63 · 학과기초 12 · 교양 30)
- 이수: 교양 7과목(18학점), 학문기초 2과목 + 학과기초 3과목(15학점), 전공 10과목(30학점), 자유선택 2과목(5학점, 타과 영양학 포함)
- F: 한국경제사(전공선택 3학점)
- 이번 학기 수강 중: 식품유통경제학·환경경제학·지역정책(전공 9학점), 인체의 신비(타과 2학점)
- 모듈 내 필수 6과목 중 마케팅조사분석을 아직 안 들음

| 2 | 같은 학생 · 「현재」(수강 중 제외) | 전공 **30** / 총 **68** / 필수 남음: 식품유통경제학(수강 중)·마케팅조사분석 | 같음 | ✅ |
| 3 | F 과목을 재수강해 통과 | 마지막 기록(통과)으로 인정 → 전공 39+3 = **42** | 같음 | ✅ |

## 실제 자가진단 PDF 대조

실제 학생의 자가진단 시뮬레이션 PDF 4건으로 판정 결과가 포털과 같은지 확인했다(`node scripts/validate.js`). 개인정보라 PDF와 이수 내역 파일은 저장소에 넣지 않는다.

## 아직 사람이 확인해야 하는 것

- **처음 쓰는 학생의 사용성**: 설명 없이 써 보게 하고 헷갈린 단계를 모은다.
- **학과 확인 대기**: 트랙 3개일 때 한 과목이 세 트랙 모두에 인정되는지.
